# File Organizer

A simple Python desktop app that automatically organizes files into categorized folders based on their file types.

## Features

- Automatic file organization
- Preview before organizing
- Custom categories
- Activity logging
- Undo support

## Download Executable (No Python Needed)

1. Go to [Releases](https://github.com/Gvybzy/File-Organizer/releases)
2. Download `FileOrganizer.exe`
3. Double-click `FileOrganizer.exe`
4. Start organizing!
